
## Overview

Hello and welcome to our project!
This is the first coding project given in the Data Structures Unit 1 course, winter 2022, Technion University.
In this project, a proficient system is in place for managing a tournament.


## Explanation
This is an object-oriented project, which includes many classes that are implemented together in the main PlayersManager class.
In the tournament that we managed, there are players who are divided into groups, and every player has their own statistics.

In the Library1 file, there are functions that are implemented for using the system, like adding a new player to a group, deleting players, changing a player's level and also getting some statistics like the best level players.
